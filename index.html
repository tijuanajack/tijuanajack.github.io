GrokBot Connection

GrokBot Connection is a private, single-owner tool. It lets the owner's personal assistant read the owner's own Google Contacts, for example to check upcoming birthdays. It is not offered to the public and has no sign-up.

Privacy policy

Data accessed: Read-only access to the owner's own Google Contacts, using the contacts.readonly scope. The app cannot create, edit, or delete contacts.

How it is used: The owner's assistant uses contact data only to produce private reminders and summaries for the owner.

Storage: The OAuth token is stored in one access-restricted file on the owner's private machine. Contact data is not sold, shared, or transferred to anyone, and it is not used for advertising or to train AI models.

Limited Use: This app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access: Access can be removed at any time at myaccount.google.com/permissions.
